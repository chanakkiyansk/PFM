💰 Personal Finance Management System (PFM)
🚀 Overview

The Personal Finance Management System (PFM) is a web application designed to help individuals and families efficiently track their income, expenses, and financial habits.

It provides insights, predictions, and an AI-powered chatbot to improve financial decision-making.

🎯 Problem Statement

Many individuals struggle to:

Track daily expenses
Manage budgets effectively
Understand spending patterns
Plan future finances

This system solves these problems by offering a simple, smart, and interactive platform.

✨ Features

📊 Core Features

Expense Tracking (manual entry)
Income Management
Transaction History
Category-wise spending
Budget overview (Income vs Expense)


📈 Analytics

Graphical representation (Pie Chart)
Monthly/Yearly filtering
Insights on spending patterns

🤖 AI Chatbot

Add expenses using text commands
Predict future expenses
Show category-wise analysis
Provide financial alerts
👨‍👩‍👧 Family Management
Add family members
Shared financial tracking
Multi-user support

🌐 Smart System

Offline support using localStorage
Auto sync with database when online
Real-time updates

🔄 How It Works

User logs in / signs up
Adds income and expenses
Data stored locally (offline support)
When online → data syncs with database
Dashboard updates with graphs and insights
Chatbot helps analyze and predict finances
